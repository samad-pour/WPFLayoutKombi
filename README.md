# WPFLayoutKombi

Ein Visual-Studio-Projekt zur Einführung in die Kombination verschiedener Layout-Elemente innerhalb einer WPF-Anwendung.

## Beschreibung

Das Projekt **WPFLayoutKombi** beschäftigt sich mit den Grundlagen der Layoutgestaltung in Windows Presentation Foundation (WPF). Im Mittelpunkt stehen die Kombination unterschiedlicher Layout-Container, die Anordnung von Steuerelementen und die strukturierte Gestaltung grafischer Benutzeroberflächen.

## Funktionen

- Kombination verschiedener WPF-Layout-Container
- Anordnung und Positionierung von Steuerelementen
- Strukturierung grafischer Benutzeroberflächen
- Gestaltung flexibler und übersichtlicher Layouts
- Grundlagen der Oberflächenentwicklung mit XAML

## Technologien

- Microsoft Visual Studio
- C# / .NET
- Windows Presentation Foundation (WPF)
- XAML

## Installation und Ausführung

1. Repository klonen:

   ```bash
   git clone https://github.com/samad-pour/WPFLayoutKombi.git
   ```

2. Die Datei `WPFLayoutKombi.sln` in Visual Studio öffnen.
3. Das Projekt erstellen.
4. Die Anwendung mit `F5` starten.
